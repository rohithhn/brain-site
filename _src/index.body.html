      FAQ

      Questions, answered.

      The short version of what people ask before installing.

      What is Open Agentic Brain and Memory?

      An open-source, self-hosted long-term memory that your AI coding tools share. It captures decisions from your sessions, distills them into a wiki every night, and hands each tool a short briefing of what matters before you type.

      Which tools does it work with?

      Claude Code, Codex (CLI and desktop app), Cursor, Antigravity CLI and Kilo Code (beta) are captured, get a briefing file, and can search memory over MCP. Claude Desktop and ChatGPT desktop can search memory over MCP only. See every tool.

      Is it really free?

      Yes. It is open source under Apache-2.0. There is no account, no subscription and no server of ours.

      Where is my memory stored?

      In a SQLite database on your machine. To sync, it travels as one age-encrypted file, stored as a Release asset in a private GitHub repo that you own.

      Can anyone else read it?

      Only whoever holds your age key, which lives in your OS Keychain and is never transmitted. A leaked repo or a leaked token exposes nothing readable.

      Does it start empty?

      You choose at install: start from the past sessions your AI tools already keep on this computer, or start fresh. Change it any time with brain past-sessions on or off.

      Will it overwrite my CLAUDE.md or AGENTS.md?

      No. The briefing lives inside its own BRAIN:START/END markers, and MCP wiring is additive: it never touches entries it did not create.

      How much context does it add to each session?

      The start-up briefing is capped at 2,000 tokens. Anything older, the model can search for when it needs it.

      Does it work across machines?

      Yes. brain sync on one machine and brain restore on the next; brain merge reconciles memory from more than one. Sync is daily and sends one whole encrypted file.

      Which platforms are supported?

      macOS and Linux, with Node 22+, git and a GitHub account. Windows is not supported yet.

      I use claude-mem. Can I switch?

      Yes. brain switch-from-claude-mem previews the move, --apply imports your whole history read-only and verified, and --undo puts claude-mem back exactly as it was.
