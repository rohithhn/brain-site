Privacy

Your memory is yours.

Agentic Brain is built so that we never see your data. This page explains what the website and the software do.

Last updated 3 October 2026

This website

  • No accounts, no forms, no cookies, no analytics and no tracking scripts.
  • The pages are static files hosted on GitHub Pages. GitHub may log your IP address when it serves them, under GitHub's own privacy statement.
  • Fonts load from Google Fonts, so your browser asks Google's servers for the font files.
  • The brain animation and every other effect run entirely in your browser.

The Agentic Brain software

  • It runs on your machine. Your memory lives in a local SQLite database in your home folder.
  • We run no server. Nothing you capture is sent to us, and the software has no telemetry or usage analytics.
  • Sync goes to your own GitHub. When you sync, the memory is encrypted with age and uploaded as a Release asset to a private repository in your own GitHub account.
  • Only you hold the key. The encryption key is kept in your operating system's keychain and is never uploaded. If you lose it, nobody, including us, can recover your memory.
  • Distilling uses your AI tool. To turn sessions into memories, Agentic Brain asks the AI tool you choose (Claude, Codex or Gemini) under your own account, so that content is handled by that provider's terms.
  • Secrets are scrubbed first. API keys and tokens are removed before anything is stored or written into instruction files. This is best effort, not a guarantee.
  • Optional semantic search runs locally. If you turn it on, a small open model is downloaded once and then runs on your machine.

Your control

  • Search, edit, pin, delete and restore any memory in the local control panel.
  • Export everything to plain JSONL with brain export.
  • Delete the local database and your private repository to remove it all.
