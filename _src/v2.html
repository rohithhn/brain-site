How it works

A loop, not a chat product.

Every session teaches the memory. Every new session starts with what matters.

Capture

Sessions from Claude Code, Codex, Cursor, Antigravity and Kilo Code, including the history already on your machine.

Distill

Raw sessions become memories: decisions, preferences, fixes. Secrets are scrubbed first.

Rank

Local hybrid search finds what's relevant to the task in front of you.

Deliver

A short briefing at session start, plus search on demand over MCP.

Measure

Every change to ranking or delivery is gated on benchmark results.

Push

Always there, zero effort.

A briefing of the current project is placed where each tool already looks at session start, capped at 2,000 tokens.

Pull · MCP

Searchable when the model needs more.

A local MCP memory server lets any connected tool recall, save and load context mid-session, including Claude Desktop and ChatGPT desktop.

Our mission
Your AI tools should remember what you taught them. And that memory should belong to you, not to whoever runs the server.
01

Owner-held

Memory lives on your machine, encrypted, and syncs only to a private GitHub repository you own. GitHub only ever sees ciphertext. No server of ours sits in the path.

02

Shared across tools

Tell one tool a decision once, and every tool you use knows it. Memory is scoped per project, with a global layer for your preferences.

03

Measured, not guessed

Public benchmarks, published answers and an open harness. If a change doesn't move the number, it doesn't ship.

FAQ

Questions

Does my code or memory go to your servers?

No. There is no server of ours. Memory is stored and searched on your machine, and synced, encrypted, to a private GitHub repository you own. The AI tools you already use see only the small briefing or search results sent to them in a session.

Which tools does it work with?

Claude Code, Codex (CLI and app), Cursor, Antigravity CLI and Kilo Code (beta) are captured and briefed. Claude Desktop and ChatGPT desktop can search the memory through MCP.

Is it really better than giving the model everything?

When the whole history fits, giving the model everything is slightly more accurate (89.3 vs 86.6 on LoCoMo) but costs about 4.6 times as much. When it doesn't fit, memory is the only option: 83.0% at 1.27 million tokens.

Can I switch from another memory plugin?

Yes. Existing history can be imported at install, so you keep what your tools already learned.

What does it cost?

Nothing. It's open source under Apache-2.0, runs on your hardware, and has no hosted tier.
