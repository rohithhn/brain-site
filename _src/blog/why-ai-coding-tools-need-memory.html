Why do AI coding assistants forget everything between sessions?

Because every session starts with an empty context window. A model only knows what is in front of it right now. When a chat ends, what you settled in it is gone, unless something writes it back into the next session.

Switching tools makes it worse. Claude Code, Codex, Cursor and Gemini CLI each keep their own history, in their own format, in their own folder. None of them can read the others. So the only thing connecting your tools is you, repeating yourself.

What does forgetting actually cost a developer?

More than the minutes spent re-explaining.

Repeated explanations

Architecture, conventions and past decisions, re-typed at the start of every session in every tool.

Decisions undone

A tool that doesn't know a decision was made will confidently reverse it: a removed library, a rejected pattern.

Fixes rediscovered

The bug that took an afternoon to understand gets debugged again, from scratch, next month.

Wasted tokens

The usual workaround is pasting long notes into the prompt. Slow, expensive, and mostly irrelevant to the task.

Lost lessons

What you learned the hard way never becomes something your tools know.

You become the glue

Every tool you add is one more place your context has to be rebuilt by hand.

Don't bigger context windows fix this?

No. A bigger window lets a model read more, not remember more. It doesn't decide what the next session should read, and it doesn't carry knowledge from one tool to another.

Filling the window is also the most expensive option. With 10,000 stored memories, pasting everything into the prompt would cost over 1.1 million tokens. The real problem isn't capacity. It's having a memory that knows what matters and delivers just that, wherever you're working.

What does a good memory for AI coding tools need?

We wrote down five requirements before writing any code.

  1. One memory for every tool. Claude Code, Codex, Cursor, Gemini CLI and Antigravity read and write the same store.
  2. Already loaded when you start. The relevant context is there before you type, without you asking.
  3. Small and relevant. A short briefing for this project, not a dump of everything ever said.
  4. Measured, not guessed. If a change makes recall worse, it doesn't ship.
  5. Owned by you. Your decisions, code and mistakes don't belong on someone else's server.

How does Agentic Brain give AI tools a memory?

It runs a loop: capture, distill, rank, inject, measure.

Capture

Reads your sessions from each tool as they happen into one local SQLite database.

Distill

Overnight, turns raw observations into a wiki it keeps revising, and drafts lessons from hard problems you solved. You approve them.

Rank

Combines search relevance with a record of what actually helped. Memories you mark helpful rise; misleading ones sink.

Inject

Writes a briefing of at most 2,000 tokens into CLAUDE.md, AGENTS.md and GEMINI.md before you type. Your own text is never touched.

Recall

Over MCP, any connected tool can search the full memory when it needs something older.

Measure

A built-in evaluation quizzes the memory on your own history. Ranking changes are gated on it.

A new conversation starts with the briefing already loaded: in about 84 ms at startup. When the model needs more, a search over 10,000 memories takes about 28 ms. And when you switch laptops, the start-up step quietly merges in what your other machine learned.

Does it keep projects separate?

Yes, memory is filed by project, but nothing is walled off. Each memory is tagged with the repository it came from. Open a folder and the briefing starts with what happened there: its recent decisions, fixes and pinned notes.

Your global instruction files also carry a short map of up to 20 projects, so a tool working in one repo still knows the others exist. Search can cover one project or all of them. Even a brand-new repo hears: "Other projects are still searchable."

Does a memory layer save tokens?

Yes. The model reads what was retrieved instead of everything.

Who owns the memory?

You do. It lives on your machine and in your own private GitHub. To sync between machines, memory is encrypted with an age key that never leaves your keychain, then stored as a release file in a private repository in your GitHub account.

No vendor server

We run nothing in the path. If a company disappears, your memory doesn't.

Only you hold the key

A leaked repository or a leaked token exposes nothing readable.

No telemetry

The software sends us nothing. Read the privacy page.

See all of it

A local control panel lets you search every memory from every tool and project.

Change any of it

Edit, pin, delete and restore memories. Approve or dismiss what it learns.

Take it with you

Export everything to plain files with one command.

Frequently asked questions

Why do AI coding assistants forget things between sessions?

Each session starts with an empty context window. Unless something writes earlier decisions back into it, the model has no record of what you settled yesterday, and each tool stores its history in a format the others can't read.

Don't bigger context windows solve this?

No. A bigger window lets a model read more in one session, but it doesn't choose what the next session should read, and it doesn't move knowledge between tools. Pasting everything in is also the most expensive option.

Can one memory work across Claude Code, Codex, Cursor and Gemini CLI?

Yes. Agentic Brain captures sessions from each tool into one local store, writes a short briefing into the instruction file each tool already reads, and exposes the same memory over MCP so any connected tool can search it.

Does adding memory use more tokens?

It uses fewer. The model reads only what was retrieved instead of a whole history: about 31.7k tokens per question instead of 127.6k in our LongMemEval-S runs, and the startup briefing is capped at 2,000 tokens.

Where is my memory stored?

On your machine, in a local database. For sync it's encrypted with a key that never leaves your keychain and stored in a private repository in your own GitHub account. There's no vendor server and no telemetry.

When is Agentic Brain available?

It's almost ready. Setup will be one command that connects your AI coding tools, creates your private memory repository and generates your key. Already using another memory tool? One command will bring your history across.
