02 · Install

One command wires Claude Code and every other tool on your machine.

  1. Run the installer. It creates your private data repo on GitHub, generates your key into the Keychain, and asks whether to start with your past AI sessions or fresh.
    curl -fsSL https://raw.githubusercontent.com/rohithhn/Open-Agentic-Brain-and-Memory/main/install.sh | bash
    macOS or LinuxNode 22+gitA GitHub account
  2. It wires Claude Code. The installer registers the brain's MCP server, writes a ~2,000-token briefing into CLAUDE.md inside BRAIN:START/END markers, and captures each session as you work.
  3. Check it. Open a new Claude Code session and run /mcp: the brain's tools are listed. Then ask “What should I know before working on this repo?” For a full read-only check of every tool, run brain doctor.

03 · Questions

Connecting Claude Code

Do I need an account or an API key?

No. There's no account and no server of ours. The memory lives in a SQLite file on your machine, and travels as one age-encrypted file to a private GitHub repo you own.

Will it overwrite my instructions file?

No. The briefing lives inside its own BRAIN:START/END markers, and MCP wiring is additive: it never touches entries it didn't create.

Does Claude Code see what I did in other tools?

Yes. There's one store for every tool on the machine, and your other machines get it through brain sync and brain restore.

What platforms work?

macOS and Linux, with Node 22+, git and a GitHub account. Windows isn't supported yet.
